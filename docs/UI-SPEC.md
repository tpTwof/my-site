# tpTwo 前端展示规范

## 视觉风格

- **整体风格**: 极简文字优先，大量留白，聚焦内容
- **配色**: 全站统一黑底浅字（包括文章、作品、联系与管理端），仅首页欢迎开场使用白底；不恢复旧主题设置，导航栏不提供主题切换按钮
- **布局宽度**: 正文 `max-w-5xl` (1024px) 水平居中；顶部导航横跨屏幕，左右留白
- **组件库**: shadcn/ui + Tailwind CSS v4
- **技术栈**: Vite + React + TypeScript

## 路由结构

| 路由 | 页面 | 导航栏 | 说明 |
|------|------|--------|------|
| `/` | 首页重定向 | ✅ 有 | 自动跳转 `/home`，替换历史记录 |
| `/home` | About me 首页 | ✅ 有 | 首次直接进入或刷新首页播放 Welcome，结束后显示个人介绍与路程轴 |
| `/posts` | 博客列表 | ✅ 有 | 已发布文章列表，无限滚动 |
| `/posts/:slug` | 文章详情 | ✅ 有 | Markdown 渲染 |
| `/tags/:slug` | 分类文章列表 | ✅ 有 | 当前分类名称、文章总数及无限滚动列表 |
| `/works` | 作品展示 | ✅ 有 | 纯前端页面，暂显示作品整理中的空状态 |
| `/contact` | 联系方式 | ✅ 有 | 纯前端页面，提供现有公开主页链接 |
| `/login` | 管理端登录 | ✅ 有 | 未登录访问 `/admin/**` 时跳到这里 |
| `/admin/posts` | 文章管理列表 | ✅ 有 | 🔒 需登录，含草稿，可过滤/编辑/删除 |
| `/admin/posts/new` | 新建文章 | ✅ 有 | 🔒 需登录，分栏编辑器 |
| `/admin/posts/:id/edit` | 编辑文章 | ✅ 有 | 🔒 需登录，分栏编辑器 |

> **首页语义**：原 `/` 欢迎页迁移到 `/home`，移除 Enter；原 `/home` 导航页撤销。
> 全站共用顶部导航，通过菜单按钮呼出站点入口，所有新增页面也使用此导航。

### 全屏菜单

全屏菜单内使用紧凑文字导航，使用 `InteractiveHoverLinks` 组件
（`src/components/ui/interactive-hover-links.tsx`）。

- 导航项由 `navbar.tsx` 中的 `MENU_LINKS` 配置
- 固定四个入口：`HOME`（/home）、`POSTS`（/posts）、`WORKS`（/works）、`CONTACT`（/contact）
- 左侧分别显示竖排小字「主 × 页」「文 × 章」「作 × 品」「联 × 系」
- 菜单列表移除 GitHub 和 Admin 项；全站导航栏的 GitHub 图标与已有管理端路由保留
- 使用 Base UI Dialog，支持关闭按钮、Escape、焦点约束与返回菜单触发按钮
- 点击链接自动关闭菜单；页面滚动在菜单打开期间锁定，菜单内容可独立滚动
- **菜单按钮动效**：初始为两条横杠；悬停时上横杠缩短，右侧出现圆点；点击打开菜单变为 ×；打开后移开鼠标变为旋转 45° 的除号，再悬停恢复 ×。关闭后回到双横杠或悬停态。
  - 两处按钮共享弹簧动画进度，弹层切换与快速移入移出时连续衔接；键盘聚焦提供相同反馈，系统偏好减少动态效果时直接切换。
  - 悬停时加大上下线间距与上横杠收缩幅度，整体轻微放大；弹簧采用适度回弹，增强变形张力。
- **悬停效果**：
  1. 整行文字容器左移 16px，同时内部每个字母再右移 16px（`staggerChildren: 0.075`，
     `delayChildren: 0.25`），产生「逐字拉长」的错位感
  2. 标题与左侧小字由 `text-muted-foreground` 变为绿色 `text-primary`
- 移除副标题、底部分隔线与右侧呼出箭头
- 标题字号 40px / `sm:text-5xl` (48px)，使用全站 Geist 字体、`font-medium` (500)；小字 10px
- 菜单靠左上排列：顶部栏下方留 8px，桌面左侧留 18vw，小屏留 24px；内容超高时可滚动

> **图片浮动效果已移除**：原组件的鼠标跟随图片（`useMotionValue` + `useSpring`）
> 整段删除，导航项不含任何图片。

## 管理端 (`/admin/posts`)

> 🔒 **需要登录**。`/admin/**` 全部由 `RequireAuth` 守卫；未登录跳转 `/login`，
> 登录后回到原地址。任何接口返回 401 时，`AuthProvider` 会清空登录态并触发跳转。

### 文章列表 (`/admin/posts`)

- 顶部：标题「文章管理」+ 总数 + 「新建文章」按钮
- 过滤栏：**NavTabs 胶囊导航**（`src/components/ui/nav-tabs.tsx`），居中
  - 全部 / 已发布 / 草稿，对应 `?status=` 参数
  - 滑块跟随鼠标，无悬停时停在当前选中项
  - 被滑块覆盖的 Tab 文字切到 `text-background`，形成白底黑字
  - **不使用 `mix-blend-difference`**：受控组件本就知道当前项，直接切色更可靠，暗色也自洽
- 列表项（悬停浮起样式，与博客列表的「卡片浮起」一致）：
  - 标题 `text-lg font-semibold`，静止时 `text-muted-foreground`，悬停变 `text-foreground`
  - 状态下徽章（已发布 / 草稿）
  - 副行：`/posts/{slug}` + 英文短日期
  - 悬停：上浮 2px + `var(--card)` 背景 + 阴影，分隔线淡出
  - **操作区**：编辑 / 删除**图标按钮**（无文字，36×36，图标 20px），
    悬停或键盘聚焦时从右侧滑入（`opacity 0→1`，`x 32→0`）
  - 隐藏状态下 `pointer-events: none`，避免误点到看不见的按钮；
    用 `focus-within` 让键盘用户也能看到操作区
  - 原组件的右侧箭头由此操作区替代
- 删除前 `confirm()` 二次确认
- 一次拉取上限 50 篇；超过后需改成分页
- **切换过滤时回到顶部**：过滤后条目数不同（如 9 篇 → 1 篇），列表高度骤减会让
  浏览器强制回滚 `scrollY`，表现为页面抖动；此处显式 `window.scrollTo(0, 0)`，
  让行为可预期
- 切换过滤期间：`initialLoading` 只用于首次加载；后续切换用 `refreshing`（列表降透明度），
  不卸载列表

### NavTabs 组件说明

参考实现来自 `docs/design/导航栏标题.md`，做了以下适配：

| 参考实现 | 本项目 |
|---|---|
| `framer-motion` | `motion/react`（项目已装） |
| `mix-blend-difference` + 硬编码黑白 | 滑块 `bg-foreground`，文字按覆盖状态切 `text-background` |
| 写死 5 个 Tab | 受控组件 `items` / `value` / `onChange` |
| `setPosition: any` | 显式 `CursorState` 类型 |
| 鼠标移开滑块消失 | 移开后滑块停回当前选中项 |
| `"use client"` | 删除（Vite 无此指令） |

### 新建 / 编辑 (`/admin/posts/new`、`/admin/posts/:id/edit`)

- 顶部操作栏：返回、标题、状态提示、「查看」、保存草稿、发布
- 表单：标题（必填）、Slug（留空自动生成，placeholder 显示自动结果）
- 正文：**SplitEditor 组件**（`src/components/split-editor.tsx`）
  - 左：Markdown 源码（`<textarea>`，等宽字体）
  - 右：实时预览（复用 `react-markdown` + `remark-gfm` + `rehype-highlight`）
  - 滚动按**比例**双向同步（rAF 节流，防止两边 scroll 事件互相触发）
- 「保存草稿」→ `status: "draft"`；「发布」→ `status: "published"`
- 新建成功后自动切到 `/admin/posts/{id}/edit`（replace），后续保存走 PUT
- 有未保存改动时，关闭/刷新页面触发 `beforeunload` 拦截
- 错误（如 slug 冲突 409）以红色提示条 + toast 展示

### 操作反馈（Toast）

使用 `sonner`（`src/components/ui/sonner.tsx`），已从 `next-themes` 改为读取本项目的 `ThemeProvider`。
挂载在 `App` 内部（`<Toaster position="bottom-right" richColors closeButton />`）。

| 场景 | 提示 |
|------|------|
| 保存草稿 | 「草稿已保存」+ 说明「只有你能看到，发布后才会出现在文章列表」 |
| 发布 | 「已发布」+ 文章路径，附「查看」按钮（新标签页打开） |
| 删除 | 「已删除」+ 文章标题 |
| 保存/删除失败 | 「保存失败」/「删除失败」+ 后端返回的具体原因 |
| 标题为空 | 「标题不能为空」 |

> 保存后**停留在编辑页**（不跳回列表），因为发布后常需回头微调；
> 反馈由 toast 承担，而非通过页面跳转暗示成功。

## About me 首页与欢迎开场 (`/home`)

开场与布局位于 `src/pages/HomePage.tsx`、`src/pages/home.css`；标题交互位于 `src/components/elastic-about-heading.tsx`，路程交互位于 `src/components/journey-map.tsx` 与 `src/components/journey-route.tsx`。全程保持 `/home` 路由。

### 播放规则

- 首次直接打开 `/` 或 `/home`、刷新首页：从白底、字母尚未飞入的状态开始播放。
- 点击站名 tpTwo、菜单 HOME、浏览器站内前进后退返回首页：直接显示 About me，不重复播放。
- 直接打开文章等其它页面后，再通过站内链接进入首页：不播放开场。
- 播放标记只保留在当前文档的模块内存中，不写入 sessionStorage；刷新会重置。
- 系统设置减少动态效果时直接显示 About me；开场期间提供「跳过动画」。

### 动画衔接

1. `Welcome to tpTwo` 的字符从屏幕四周飞入并排成一行，使用位移与旋转，逐字延迟。
2. 最后一个字符到位后，整行播放一次逐字波浪。
3. 黑色 About me 页面带着半椭圆顶部自下向上展开；上升开始 0.65 秒后，导航携带浅色文字与半椭圆底边从顶部向下展开，两部分在 1.8 秒时同时收平合拢。
4. 展开结束移除欢迎层，解锁页面滚动。

正文在展开期间保持正常文档布局，通过 `translate3d` 移动；半椭圆使用独立伪元素缩放。
预留滚动条空间，避免动画结束时因定位切换或宽度变化发生跳动。导航过渡使用裁切的黑色视觉副本（`aria-hidden`、`inert`），不重复响应点击或键盘焦点；不再直接渐变整栏背景。

### About me 标题与留白

- 拖动绿色句点时，A 固定，其余字母随牵引逐渐拉开间距；标题保持正常布局，交互位移不推挤下方内容。
- 句点左端跟随 e，两者保持 `.06em` 间隔；句点形状独立横向拉长，形变由牵引两端的位移和速度差决定，停住鼠标后逐渐恢复。
- 松手后播放与 Welcome 相同的上扬、轻微下落、归位节奏，波浪由右向左传播，e 与句点同步，结束时精确恢复原位置与形状。
- 支持鼠标、触屏拖动；键盘聚焦句点后可按住左右方向键牵引、松开回弹，Escape 结束牵引。指针取消或窗口失焦也会释放；调整窗口尺寸时复位。
- 减少动态效果时关闭句点形变与波浪，保留平缓归位。
- 介绍区域底部留白为 30px；「时间长廊...」入口为 21px。路程区域顶部留白 32px，路程组件另有 20px 顶部留白。

### About me 路程轴

- 黑底浅字，包含 About me 标题、简短介绍、向下浏览入口与可滚动到底部的路程轴。
- 仅采用参考图左侧的圆点与纵向连线结构，不使用其公司、职位、技术标签等内容。
- 路程由 `JourneyMap` 显示：起点固定为三个英文介绍节点（CS · FULL_STACK、READER、GAMER），在前端 `INTRO` 中硬编码且不可通过管理入口修改。后续日常记录从 `GET /api/journey` 加载并追加；即使接口为空或失败，三个介绍节点仍然显示。
- 管理员登录后，首页路程标题旁显示「添加路程」；后续日常记录可编辑或删除。支持日期/阶段、完整短文字及一张可选图片，保存到后端数据库。
- 图片可从本地选择 PNG、JPEG、WebP、GIF，最大 2MB；当前以 data URL 存储，无需外部图床。作品与联系页仍保持纯前端。
- 节点左右交替，每个节点到中轴的水平距离从路程容器总宽的 0.1、0.15、0.2 中随机选择，当前挂载期间保持稳定。
- 桌面文字在节点外侧左右展示，宽度固定为 `min(260px, 30% - 24px)`；窄屏移到内侧，宽度为 `60% - 32px`，避免挤出视口。
- 使用 ResizeObserver 测量文字实际高度，下一节点纵向间距为 `max(230px, 文字高度 + 110px)`；连线沿节点向下，在正文底部之后转折到下一节点。换行、改字、图片加载、窗口变化不会让节点压住正文。
- 文字完整展示，不截断。图片不参与文字排版，也不改变节点间距。
- 有图片的节点悬停或聚焦时，照片从小到大向上浮现；移开后缩小淡出。每次进入随机生成 -30° 至 +30° 的平面旋转，不镜像或翻转。没有图片时不生成照片层。
- 节点有 44px 点击区域，支持键盘聚焦和触屏点按；减少动态效果时仅淡入淡出。绿色节点与日期标记、红色末节点，正文使用白色及中性灰阶。
- 无 Enter 按钮，站点导航由顶部菜单统一提供。

### 沿线圆点拖动与终点配色

- 普通悬停或键盘聚焦时，节点填充自身颜色并显示一圈圆环；普通鼠标移动不会激活沿线圆点。
- 在节点或连线附近按住鼠标左键开始拖动，显示直径 13px 的移动圆点；连线具有 24px 宽的透明命中区域，图上仍只绘制细线。
- 鼠标坐标投影到折线，圆点始终沿线移动；使用指针捕获，拖出原命中区域仍可继续操作，滚动页面后按当前指针位置更新投影。
- 圆点距节点沿路距离不超过 8px 时吸附到节点，并显示两圈同心圆环；离开节点后取消到达效果，悬停与到达状态分别控制。
- 松开左键后，圆点按路径距离依次经过折角、返回顶部第一个节点并消失，返程不跟随鼠标。指针取消、捕获丢失、窗口失焦或 Escape 同样触发返程；返程途中重新按住节点或连线可再次接管。
- 返程时长按距离计算，限制在 300–2400ms，并逐渐减速；减少动态效果时直接回到首节点后隐藏。
- 实际最后一个节点使用红色，包括空心边框、悬停填充、单圈、到达双圈和焦点轮廓。其余节点使用绿色；身份标题仍为绿色。终点随日常记录增删而更新，不固定为第三个介绍节点。
- 移动圆点在倒数第二个节点之前保持绿色；从倒数第二个节点开始，按到最后节点的整段折线路程逐渐变红，到终点为纯红。返程沿同一路段由红变绿。
- 绘制、投影与返程共用 `src/lib/journey-route.ts` 的路径几何；节点位置或内容高度改变时取消当前拖动与动画，避免沿旧路径显示。
- 沿线拖动仅响应鼠标左键；节点的触屏照片点按与键盘聚焦继续保留。

## 博客列表页 (`/posts`)

- 使用 **PostCardList**（`src/components/ui/post-card-list.tsx`），经典博客风格
- 样式取自一份 Jekyll 主题参考站，**以本项目为准做了裁剪**：
  - 类型用 `PostSummary`（后端真实字段），不是参考站的 `Post`
  - 链接用 React Router `<Link to>`，不是 `<a href>`（避免整页刷新）
  - 删除 `Paginator`：分页由外层 `Posts.tsx` 的无限滚动负责
  - 删除 `"use client"`、`forwardRef`、`category`（均无效或未使用）
- 每项结构：
  1. 主标题 `text-[26px] leading-[48px] font-bold`，链接色 `--post-link`
  2. 日期 `02 Oct 2026` 英文短格式，色 `--post-muted`
  3. `<hr>` 分隔线
  4. 摘要（后端 `summary` 字段），色 `--post-body`
  5. 「阅读全文 »」链接
  6. `<hr>` 分隔线
- **悬停效果**：
  1. 左侧 15px 红色竖条从透明显现（`border-l-transparent` → `border-l-[var(--post-accent)]`）
  2. 文字区右移 30px（`hover:pl-[30px]`）
  3. 过渡 `duration-300 ease-linear`（匀速。参考站也用 `linear`，本项目沿用其手感）
- **配色走 CSS 变量**：由 `index.css` 的 `:root, .dark` 统一定义，不再沿用参考稿的蓝色链接

| 变量 | 当前值 | 用途 |
|------|------|------|
| `--post-link` | `var(--brand-green)` / `#8df58b` | 标题 / 阅读全文链接 |
| `--post-link-hover` | `var(--brand-white)` / `#f4f4f2` | 链接悬停 |
| `--post-accent` | `var(--brand-red)` / `#ff6464` | 左侧红条 |
| `--post-muted` | `var(--muted-foreground)` / `#a3a3a3` | 日期 |
| `--post-body` | `var(--foreground)` | 摘要正文 |
| `--post-rule` | `var(--border)` / `#303030` | 分隔线 |

### 当前分类与数量

`PostCategoryHeading` 在文章列表顶部显示当前分类名称与文章总数（例如 cpp · 1 篇文章）。
All 显示已发布文章总数；分类页显示标签接口中的 `count`，不使用当前已加载的文章条数。
数量不受分页与侧栏搜索影响；数据返回前显示「加载中…」。适用于 `/posts?tag=...` 与 `/tags/:slug`。

- **分页**: 无限滚动（游标分页），滚动到底部自动加载更多
- **数据**: 仅展示 `status = "published"`，列表项不含正文（用 `summary` 字段）
- 点击标题或「阅读全文」→ 跳转 `/posts/:slug`

## 文章详情页 (`/posts/:slug`)

- Markdown 渲染: `react-markdown` + `remark-gfm` + `rehype-highlight`
- 支持 GFM 语法（表格、任务列表、删除线）
- 代码块语法高亮以 highlight.js `github-dark.css` 为基础，再由全局 CSS 统一为黑白绿红；管理端预览使用相同规则
- 显示：标题、发布日期、正文
- 日期格式与列表一致（`formatCardDate`：`02 Oct 2026`）
- 加载失败或文章不存在 → 重定向回 `/posts`

---

## 数据层约定

- 类型定义集中在 `src/types/post.ts`，与后端 schema 一一对应：
  - `PostSummary` ← 列表项（无正文）
  - `PostDetail` ← 详情（含 `content_markdown`）
  - `PostStatus` = `'draft' | 'published'`（联合字面量，不用裸 `string`）
- API 调用集中在 `src/lib/api.ts`，页面不直接 `fetch`
- 通用工具（`cn`、`formatCardDate`）放 `src/lib/utils.ts`，不在页面间复制
- **日期格式全局统一**为 `02 Oct 2026`（`formatCardDate`），列表 / 详情 / 管理端共用。
  月份用固定缩写表而非 `toLocaleDateString`——en-GB 下九月是 `Sept`（四字母），会撑宽布局。

## 当前统一配色

以 `src/index.css` 的语义变量为准，黑、白、绿、红应用到全站。

| 颜色 | 色值 | 用途 |
|---|---|---|
| 黑 | `#101010` | 页面与导航背景 |
| 白 | `#f4f4f2` | 正文、标题；灰阶用于次要信息与分隔线 |
| 绿 | `#8df58b` | 文章链接、菜单悬停、主要按钮、焦点、时间轴节点、成功提示 |
| 红 | `#ff6464` | 悬停强调条、时间轴末节点、危险操作、错误与警告 |

仅 Welcome 开场保留白底黑字。代码高亮和提示消息使用同一配色，不再引入蓝、紫、黄。

### 固定介绍节点的视觉层级

三个固定节点采用同一行的编号与身份：01 / CS · FULL_STACK、02 / READER、03 / GAMER。编号和身份同为绿色，身份为 14–26px、600 字重，编号为 12px；下方灰色英文寄语为 16px、1.7 行高。文字块宽度不变，ResizeObserver 测量整块高度并继续避让折线与下一节点。

### 文章阅读页配色例外

/posts、/tags/:slug 和文章详情使用局部 data-reading-page 配色：分类名称、文章标题及其它原绿色交互改为白色；「阅读全文」始终采用与左侧强调条相同的红色（包括已访问与悬停状态），悬停增加下划线；首页路程图仍使用绿色身份标题。
