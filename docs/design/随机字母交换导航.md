你的任务是将一个现有的 React 组件集成到代码库中。

代码库应支持：
- shadcn 项目结构
- Tailwind CSS
- Typescript

如果不支持，请提供通过 shadcn CLI 设置项目、安装 Tailwind 或 Typescript 的说明。

确定组件和样式的默认路径。
如果组件的默认路径不是 /components/ui，请提供关于为何创建此文件夹很重要的说明。
将此组件复制粘贴到 /components/ui 文件夹中：
```tsx
text-roll.tsx
"use client"

import React from "react"
import { motion } from "motion/react"

import { cn } from "@/lib/utils"

const STAGGER = 0.035

export default function TextRoll({
  children,
  className,
  center = false,
}: {
  children: string
  className?: string
  center?: boolean
}) {
  return (
    <motion.span
      initial="initial"
      whileHover="hovered"
      className={cn(
        "relative block overflow-hidden text-black dark:text-white/90",
        className
      )}
      style={{
        lineHeight: 0.85,
      }}
    >
      {/* 顶部文字（向上滑动） */}
      <div>
        {children.split("").map((l, i) => {
          const delay = center
            ? STAGGER * Math.abs(i - (children.length - 1) / 2)
            : STAGGER * i

          return (
            <motion.span
              variants={{
                initial: {
                  y: 0,
                },
                hovered: {
                  y: "-100%",
                },
              }}
              transition={{
                ease: "easeInOut",
                delay,
              }}
              className="inline-block"
              key={i}
            >
              {l}
            </motion.span>
          )
        })}
      </div>

      {/* 底部文字（从下方滑入） */}
      <div className="absolute inset-0">
        {children.split("").map((l, i) => {
          const delay = center
            ? STAGGER * Math.abs(i - (children.length - 1) / 2)
            : STAGGER * i

          return (
            <motion.span
              variants={{
                initial: {
                  y: "100%",
                },
                hovered: {
                  y: 0,
                },
              }}
              transition={{
                ease: "easeInOut",
                delay,
              }}
              className="inline-block"
              key={i}
            >
              {l}
            </motion.span>
          )
        })}
      </div>
    </motion.span>
  )
}
```

安装 NPM 依赖：
```bash
clsx, motion, tailwind-merge
```

实施指南
 1. 分析组件结构并确定所有必需的依赖项
 2. 审查组件的参数和状态
 3. 确定是否需要上下文提供者（Context Providers）或钩子（Hooks），并进行安装
 4. 需要确认的问题
 - 将向此组件传递哪些数据/属性？
 - 是否有特定的状态管理需求？
 - 是否需要任何资源文件（图片、图标等）？
 - 预期的响应式行为是什么？
 - 在应用中使用此组件的最佳位置在哪里？

集成步骤
 0. 将上述所有代码复制粘贴到正确的目录中
 1. 安装外部依赖
 2. 使用你已知存在的 Unsplash 库存图片填充图像资源
 3. 如果组件需要 SVG 或 Logo，请使用 lucide-react 图标
