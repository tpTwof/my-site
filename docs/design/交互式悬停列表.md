# 交互式悬停列表 (Interactive Hover List)

## 效果描述

垂直排列的列表组件，每项包含大号粗体标题 + 小号副标题。

### 静态状态
- 每项之间用细灰线分隔
- 标题为浅灰色，副标题为更浅的灰色
- 整体安静、低对比度

### 悬停状态（鼠标移入某一项时）
1. **卡片浮起**: 该项从扁平列表行变为浮起的卡片——白色背景 + 圆角 + 阴影 + 微微上浮 2px
2. **分隔线淡出**: 分隔线消失，被卡片阴影替代
3. **文字变黑**: 标题从浅灰变为纯黑加粗，副标题也变深
4. **箭头出现**: 最右侧出现 `→` 箭头，向左滑出 70px，暗示可点击

### 离开状态
所有动画反向播放，回到静态状态。

## 技术依赖

- React
- motion/react (Framer Motion)
- Tailwind CSS
- TypeScript
- shadcn 项目结构

## 组件代码

将此组件复制到 `/components/ui` 文件夹中：

```tsx
interactive-hover-list.tsx
"use client"

import React, { useState } from "react"
import { motion, AnimatePresence } from "motion/react"
import { ArrowRight } from "lucide-react"
import { cn } from "@/lib/utils"

// ===== 类型定义 =====
interface HoverListItem {
  id: string
  title: string
  subtitle: string
  href?: string
}

interface InteractiveHoverListProps {
  items: HoverListItem[]
  className?: string
  onItemClick?: (item: HoverListItem) => void
}

// ===== 单个列表项 =====
function HoverItem({
  item,
  isHovered,
  onHover,
  onLeave,
  onClick,
}: {
  item: HoverListItem
  isHovered: boolean
  onHover: () => void
  onLeave: () => void
  onClick: () => void
}) {
  return (
    <motion.div
      className="relative cursor-pointer rounded-xl px-6 py-8"
      onMouseEnter={onHover}
      onMouseLeave={onLeave}
      onClick={onClick}
      animate={{
        y: isHovered ? -2 : 0,
        backgroundColor: isHovered ? "#fff" : "transparent",
        boxShadow: isHovered
          ? "0 10px 40px -10px rgba(0,0,0,0.15), 0 2px 10px -2px rgba(0,0,0,0.08)"
          : "0 0 0 0 transparent",
      }}
      transition={{ duration: 0.3, ease: "easeOut" }}
    >
      {/* 分隔线：悬停时淡出 */}
      <motion.div
        className="absolute bottom-0 left-6 right-6 bg-gray-200"
        animate={{
          height: 1,
          opacity: isHovered ? 0 : 1,
        }}
        transition={{ duration: 0.3 }}
      />

      <div className="flex items-center justify-between">
        <div>
          {/* 标题 */}
          <motion.h2
            className="m-0 text-4xl font-bold tracking-tight lg:text-5xl"
            animate={{
              color: isHovered ? "#000" : "#9ca3af",
            }}
            transition={{ duration: 0.3 }}
          >
            {item.title}
          </motion.h2>

          {/* 副标题 */}
          <motion.p
            className="mt-2 text-sm"
            animate={{
              color: isHovered ? "#374151" : "#d1d5db",
            }}
            transition={{ duration: 0.3 }}
          >
            {item.subtitle}
          </motion.p>
        </div>

        {/* 箭头：从右向左滑入 */}
        <AnimatePresence>
          {isHovered && (
            <motion.div
              initial={{ opacity: 0, x: 0 }}
              animate={{ opacity: 1, x: -70 }}
              exit={{ opacity: 0, x: 0 }}
              transition={{ duration: 0.25 }}
            >
              <ArrowRight size={28} className="text-black" />
            </motion.div>
          )}
        </AnimatePresence>
      </div>
    </motion.div>
  )
}

// ===== 主组件 =====
export default function InteractiveHoverList({
  items,
  className,
  onItemClick,
}: InteractiveHoverListProps) {
  const [hoveredId, setHoveredId] = useState<string | null>(null)

  return (
    <div className={cn("w-full", className)}>
      {items.map((item) => (
        <HoverItem
          key={item.id}
          item={item}
          isHovered={hoveredId === item.id}
          onHover={() => setHoveredId(item.id)}
          onLeave={() => setHoveredId(null)}
          onClick={() => onItemClick?.(item)}
        />
      ))}
    </div>
  )
}

export type { HoverListItem, InteractiveHoverListProps }
```

## 实施指南

1. 分析组件结构并确定所有必需的依赖项
2. 审查组件的参数和状态
   - `items`: HoverListItem[] — 列表数据，每项含 id, title, subtitle, href(可选)
   - `onItemClick`: 点击回调
   - `hoveredId`: 内部状态，追踪当前悬停项
3. 确定是否需要上下文提供者或钩子
   - 不需要额外的 Context Provider
4. 需要确认的问题
   - 暗色模式下的颜色是否需要调整？
   - 箭头滑入距离 70px 是否合适？

## 集成步骤

0. 将上述代码复制到正确的目录中
1. 安装外部依赖
2. 准备列表数据，转换为 HoverListItem[] 格式传入
3. 如需配合路由跳转，在 onItemClick 中使用 navigate()
