你的任务是将一个现有的 React 组件集成到代码库中。

代码库应支持：
- shadcn 项目结构
- Tailwind CSS
- Typescript

如果不支持，请提供通过 shadcn CLI 设置项目、安装 Tailwind 或 Typescript 的说明。

确定组件和样式的默认路径。
如果组件的默认路径不是 /components/ui，请提供关于为何创建此文件夹很重要的说明。
将此组件复制粘贴到 /components/ui 文件夹中：
```tsx
interactive-hover-button.tsx
import React from "react";
import { ArrowRight } from "lucide-react";
import { cn } from "@/lib/utils";

interface InteractiveHoverButtonProps
  extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  text?: string;
}

const InteractiveHoverButton = React.forwardRef<
  HTMLButtonElement,
  InteractiveHoverButtonProps
>(({ text = "按钮", className, ...props }, ref) => {
  return (
    <button
      ref={ref}
      className={cn(
        "group relative w-32 cursor-pointer overflow-hidden rounded-full border bg-background p-2 text-center font-semibold",
        className,
      )}
      {...props}
    >
      <span className="inline-block translate-x-1 transition-all duration-300 group-hover:translate-x-12 group-hover:opacity-0">
        {text}
      </span>
      <div className="absolute top-0 z-10 flex h-full w-full translate-x-12 items-center justify-center gap-2 text-primary-foreground opacity-0 transition-all duration-300 group-hover:-translate-x-1 group-hover:opacity-100">
        <span>{text}</span>
        <ArrowRight />
      </div>
      <div className="absolute left-[20%] top-[40%] h-2 w-2 scale-[1] rounded-lg bg-primary transition-all duration-300 group-hover:left-[0%] group-hover:top-[0%] group-hover:h-full group-hover:w-full group-hover:scale-[1.8] group-hover:bg-primary"></div>
    </button>
  );
});

InteractiveHoverButton.displayName = "InteractiveHoverButton";

export { InteractiveHoverButton };


demo.tsx
import { InteractiveHoverButton } from "@/components/ui/interactive-hover-button";


function InteractiveHoverButtonDemo() {
  return (
    <div className="relative justify-center">
      <InteractiveHoverButton />
    </div>
  );
}

export { InteractiveHoverButtonDemo };
```

安装 NPM 依赖：
```bash
lucide-react
```

实施指南
 1. 分析组件结构并确定所有必需的依赖项
 2. 审查组件的参数和状态
 3. 确定是否需要上下文提供者（Context Providers）或钩子（Hooks），并进行安装
 4. 需要确认的问题
 - 将向此组件传递哪些数据/属性？
 - 是否有特定的状态管理需求？
 - 是否需要任何资源文件（图片、图标等）？
 - 预期的响应式行为是什么？
 - 在应用中使用此组件的最佳位置在哪里？

集成步骤
 0. 将上述所有代码复制粘贴到正确的目录中
 1. 安装外部依赖
 2. 使用你已知存在的 Unsplash 库存图片填充图像资源
 3. 如果组件需要 SVG 或 Logo，请使用 lucide-react 图标
