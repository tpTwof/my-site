## 一、标签（Tag）

### 数据规则

- 一篇文章可以有**多个标签**
- **所有文章一定有标签**：编辑时留空或不填，自动归入「其他」
- 标签名上限 **20 字符**
- 标签名**忽略大小写和首尾空格**去重（`Java` 与 `java` 视为同一个标签，展示用第一次创建时的写法）
- 输入时分隔符为**逗号**，其他空白（空格、顿号）也一并剥离

### 数据模型

```python
# backend/models/tag.py
class Tag(SQLModel, table=True):
    __tablename__ = "tags"

    id: str = Field(primary_key=True)
    name: str = Field(max_length=20)                      # 展示名
    slug: str = Field(max_length=64, index=True, unique=True)  # 归一化键


class PostTag(SQLModel, table=True):
    """文章 ↔ 标签。"""
    __tablename__ = "post_tags"

    post_id: str = Field(foreign_key="posts.id", primary_key=True)
    tag_id: str = Field(foreign_key="tags.id", primary_key=True)
```

**为什么独立建表**：改标签名只改一处；「每标签多少篇」一条 `GROUP BY`；
筛选走索引；以后能加颜色等字段。

### slug 归一化

标签只出现在**查询参数**里，不进 URL 路径，所以 slug 保留中文更可读：

```python
def tag_slug(name: str) -> str:
    """标签 slug：小写、空白转连字符、保留 Unicode 字母（含中文）。

    与文章 slug 不同——文章 slug 进 URL 路径，必须 ASCII；
    标签只作为 ?tag= 出现，可读性更重要。
    """
    s = name.strip().lower()
    s = re.sub(r"\s+", "-", s)
    s = re.sub(r"[^\w\-]", "", s, flags=re.UNICODE)
    return s or "other"
```

| 输入 | slug |
|---|---|
| `Java` | `java` |
| `C#` | `c` |
| `c/c++` | `cc` |
| `操作系统` | `操作系统` |

### 默认标签「其他」

- 常量 `DEFAULT_TAG = "其他"`，slug 为 `其他`
- 创建文章时 `tags` 为空 → 打上「其他」
- 更新时 `tags` 显式传 `[]` → 同样回落到「其他」
- 「其他」和其他标签**地位完全平等**，是真实存在的标签，不是虚拟分类

## 二、管理端编辑页的标签输入

### 位置

**标题 / Slug 那一行之下，MARKDOWN 编辑区之上**：

```
┌─────────────────────────────────────────────────────┐
│ 标题                                    Slug         │
│ [_______________________]  [_______________________] │
├─────────────────────────────────────────────────────┤
│ 标签（Tag）                                          │
│ ┌─────────────────────────────────────────────────┐ │
│ │ java, python, c#         #java  #python  #c#    │ │
│ └─────────────────────────────────────────────────┘ │
├──────────────────────────┬──────────────────────────┤
│ MARKDOWN                 │ 预览                      │
```

**同一个框里，左边是输入区，右边实时回显解析出的标签**，形式为 `#java #python #c#`。

分隔符**逗号、空格都忽略**——用户敲 `java python c#` 和 `java, python, c#`
得到相同结果。

### 回显规则

```tsx
const parsed = tagsText
  .split(/[,，\s]+/)      // 逗号（半角/全角）、空白都作分隔
  .map((s) => s.trim())
  .filter(Boolean)
  .slice(0, 10)           // 单篇最多 10 个，防止刷屏

// 展示
{parsed.map((t) => `#${t}`).join(' ')}
```

- 输入为空时，回显位置显示灰色的「默认：其他」
- 超过 20 字符的标签会被截断，并在输入框下方提示

## 三、API 变更

### 新增：标签列表（含文章数）

```
GET /api/tags
```

```json
{
  "items": [
    { "slug": "java", "name": "java", "count": 17 },
    { "slug": "其他", "name": "其他", "count": 4 }
  ],
  "total": 61
}
```

- `total` = 已发布文章总数，给「All」用
- 按 `count` **降序**，数量相同按名称升序
- 只统计**已发布**文章

### 新增：单个标签的文章列表页

```
GET /api/tags/{slug}/posts?cursor=...&limit=10
```

返回结构同 `GET /api/posts`（`PostSummaryList`），但只含该标签下的已发布文章。
404 当标签不存在。

### 修改：文章列表支持标签筛选

```
GET /api/posts?tag=java&cursor=...&limit=10
```

不传 `tag` = 全部文章。

### 修改：文章返回标签

`PostSummary` / `PostDetail` 增加：

```json
{ "tags": [{ "slug": "java", "name": "java" }] }
```

**列表要批量查**，不能 N+1。

### 修改：管理端创建/更新支持标签

```json
POST /api/admin/posts
{ "title": "...", "tags": ["Java", "SQLite"], ... }
```

- `tags` 为标签名数组
- 不存在的标签自动创建
- 传 `[]` 或不传 → 落到「其他」
- 覆盖该文章原有标签（先删后建）

**搜索框规则**（重要）：

- 输入框后面**必须有一个「搜索」按钮**
- **点击按钮或按回车**才发起搜索，**不做实时防抖搜索**
- 搜索**只过滤左侧标签列表**：只显示 name/slug 包含关键词的标签
- 关键词没有匹配到任何标签时，**标签列表留空**（不显示「无结果」提示）
- 搜索**不影响右侧文章列表**——文章列表仍显示全部（或当前标签筛选结果）

**标签项样式**：

```

│▎java              17   │  ← 选中：左侧 3px 红条 + 加粗
├────────────────────────┤
│ sqlite             3   │  ← 未选中：左边框透明占位
└────────────────────────┘
```

- 红色用 `--post-accent`，与文章列表悬停时的左边红条同色
- 悬停：文字变 `--post-link`
- 数量徽章：圆角背景 `--post-rule`，右对齐
- 侧栏白色背景，右侧一条 `--post-rule` 细线
- `sticky top-28`（导航栏 112px），自身可滚动
- 窄屏（`< lg`）折叠为顶部横向滚动条

**状态放 URL**：


## 五、后端实现要点

### 批量查标签（避免 N+1）

```python
def tags_for_posts(session: Session, post_ids: list[str]) -> dict[str, list[TagRef]]:
    if not post_ids:
        return {}
    rows = session.exec(
        select(PostTag.post_id, Tag.slug, Tag.name)
        .join(Tag, Tag.id == PostTag.tag_id)
        .where(PostTag.post_id.in_(post_ids))
        .order_by(Tag.name)
    ).all()
    grouped: dict[str, list[TagRef]] = {}
    for post_id, slug, name in rows:
        grouped.setdefault(post_id, []).append(TagRef(slug=slug, name=name))
    return grouped
```

### 标签计数

```python
def tag_with_counts(session: Session) -> TagList:
    published = Post.status == "published"
    counts = session.exec(
        select(Tag.slug, Tag.name, func.count(Post.id))
        .join(PostTag, PostTag.tag_id == Tag.id)
        .join(Post, Post.id == PostTag.post_id)
        .where(published)
        .group_by(Tag.id)
        .order_by(func.count(Post.id).desc(), Tag.name)
    ).all()
    total = session.exec(select(func.count()).select_from(Post).where(published)).one()
    return TagList(items=[...], total=total)
```

`JOIN` 天然过滤掉「没有已发布文章的标签」，避免点进去是空白页。

### 分页与筛选的兼容

- `tag` 条件必须进入**每一条**游标查询，否则翻页漏数据
- 游标本身不变（仍是 `created_at`）
- 前端切换标签时必须**清空游标**

## 七、已确认的决策

| 问题 | 决定 |
|---|---|
| 标签输入方式 | 单个输入框，逗号/空格分隔，右侧回显 `#tag` |

| 搜索触发 | 点「搜索」按钮或回车，不实时 |
| 搜索作用范围 | **只过滤左侧标签列表**，不影响文章列表 |

| 搜索框位置 | 只有 `/posts` 有 |
