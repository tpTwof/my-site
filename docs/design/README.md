# 设计参考资料

此目录保留组件原稿、历史需求与参考实现。当前页面行为与配色以 [前端展示规范](../UI-SPEC.md) 和实际源码为准。

| 参考稿 | 当前实现的主要差异 |
|---|---|
| 博客首页文章卡片列表 | 保留布局与红色悬停条；蓝色链接已改为绿色，背景统一为黑色 |
| 交互式悬停列表 | 用于菜单的 HOME / POSTS / WORKS / CONTACT；添加左侧竖排中文，移除副标题、分隔线、箭头与浮动图片 |
| 交互式悬停按钮 | 原 Enter 入口已移除；通用组件保留，当前首页不使用 |
| 下拉灯绳回到顶部 | 当前黑底页面使用白色绳子；实际颜色读取 `--lamp-*` 变量，不沿用原稿的浅色背景假设 |
| 标签与搜索 | 已实现；列表顶部另显示当前分类与文章总数，不再作为待开发需求 |

About me 的开场动画、刷新重播规则、句点弹性拖动、路程沿线圆点、到达双圈与动态红色终点见 [UI-SPEC](../UI-SPEC.md) 的首页章节。设计参考图中的静态节点颜色和间距不覆盖这些交互规则。
