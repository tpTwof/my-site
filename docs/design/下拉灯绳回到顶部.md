你的任务是将一个现有的 React 组件集成到代码库中。

代码库应支持：
- shadcn 项目结构
- Tailwind CSS
- Typescript

---

## 需求

一个**下拉灯绳**组件，下拉之后页面平滑滚回文章顶部。

**位置**：文章详情页底部，在「上一篇 / 下一篇」之上，整体靠左对齐。

**交互**：像台灯的拉绳开关。鼠标按住绳子往下拖，绳子被拉长；松手后
绳子回弹，同时页面以缓动动画滚回顶部。

**外观**：只做绳子那部分（一条细链 + 末端坠子），不画灯罩、灯杆、底座。

**配色**：**白色绳子 + 细描边**。纯白绳子放在白底页面上会消失，因此绳与
坠子都描一圈淡边，保证亮暗背景上都看得清。

---

## 与现有配色体系的关系

项目里组件只用 CSS 变量，不直接写颜色值（见 `src/index.css`）。
这个组件新增三个变量：

```css
/* 亮色：白绳靠描边立住 */
--lamp-rope: #ffffff;        /* 绳身：纯白 */
--lamp-bead: #ffffff;        /* 坠子：同色，靠描边和投影区分 */
--lamp-outline: #d4d4d8;     /* 描边：淡灰，白底上给出轮廓 */

/* 暗色：白绳本身就跳出来了，描边退到更暗 */
--lamp-rope: #ffffff;
--lamp-bead: #ffffff;
--lamp-outline: #3f3f46;
```

**为什么需要 `--lamp-outline`**：`--background` 亮色是纯白，白绳直接放上去
对比度为 1:1，等于不可见。描边提供的是"形状"而不是颜色反差——眼睛顺着
线条轮廓就能看到，这也正是真实灯绳在浅色墙面上的观感。

坠子额外带一层极淡投影，确保在纯白区域也不至于完全融掉。

## 拖动与回弹的物理感

不是普通的 `scrollTo`，要满足三个条件：

1. **拖动阶段**：绳长跟随鼠标位移线性增长，最多拉长 `MAX_PULL`（64px）
2. **松手回弹**：用 spring 回到原长，带回弹过冲（`bounce`）
3. **滚动同步**：滚回顶部用**变速**缓动——先慢、中段加速、末端减速
   （`easeInOutCubic`），耗时约 900ms，而不是浏览器的瞬时跳转

关键：**回弹动画和滚动动画同时开始**，绳子回到原位的过程就是页面
滚到顶部的过程。两者不同步会很别扭。

## 组件代码

代码见 [`frontend/src/components/ui/lamp-pull.tsx`](../../frontend/src/components/ui/lamp-pull.tsx)。

文档里不重复贴一份源码，避免实现改过之后两份对不上。以下是阅读时值得注意的几点：

| 常量 / 逻辑 | 说明 |
| --- | --- |
| `REST_LENGTH = 48` | 静止绳长。太短不像绳子，太长占版面 |
| `MAX_PULL = 64` | 最大拉伸。再长会盖住下方内容 |
| `TRIGGER_RATIO = 0.35` | 拉到 22px 以上才触发，防误触 |
| `BEAD = 12` | 坠子直径，与 3px 绳宽的比例接近真实拉绳 |
| `SCROLL_MS = 900` | 滚动总时长 |
| `easeInOutCubic` | 曲线本体；实测起步均速 4、中段 64、末段 3 |

两处容易写错的地方：

1. **滚动终点必须是 0。** 早期版本用 `window.scrollY - offset` 当起点，
   结果是滚到 `offset` 处停住，永远回不到真正的顶部。缓动只作用于
   剩余距离，终点写死 0。
2. **`touch-none` 不能省。** 触摸设备上拖动绳子时，浏览器默认会同时
   滚动页面，两个动作叠加会抖。

## 需要注意的实现细节

**滚动曲线不能偷懒用 `scrollTo({ behavior: 'smooth' })`。**
浏览器内置的 smooth 无法自定义缓动曲线，各浏览器还不一致。
用 `requestAnimationFrame` + `easeInOutCubic` 才能做到"变速"。

**回弹必须和滚动同时开始。**
如果先滚完再回弹，或先回弹再滚动，节奏会断裂。代码里两者在
`onPointerUp` 中一起启动。

**拖动阈值。**
拉满 `MAX_PULL` 的 35% 以上才算有效，防止鼠标轻微抖动误触发。

**白绳的可见性靠描边，不靠颜色反差。**
绳宽只有 1px，加 1px 边框后总宽 3px，仍是很轻的一根线。如果用
`outline` 会因为不占布局而盖住绳身，所以用 `border-x` 让描边参与宽度计算；
配合 `box-border`，改边框宽度不会让绳子左右跳动。

**暗色模式不需要特殊处理。**
`--background` 在暗色下是深色，白绳天然对比度高；只需把 `--lamp-outline`
换成深灰，避免白色线条外面套一圈更亮的光晕。
